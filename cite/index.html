How to cite

Cite the work id, the chunk locator, and the trace version hash. Statuses travel with the citation — repeat them.

Format

Svatantrya Reader, “{work} {target} ({verses})”, https://svread.pages.dev/claim/{work}/{target}/, version trace {sha}. Each claim page carries a ready copy-paste citation.

Stable-URL policy

  • Claim URLs (/claim/<work>/<target>/) are stable. Content regenerates byte-identically or not at all.
  • The trace version hash pins the exact bytes cited. A changed upstream produces a new trace, never a silent edit.
  • Work indexes (/work/<work>/) list every claim for the work.

Status words

  • COMPLETE = every applicable link resolved (not approval, proof, or witness).
  • PARTIAL = some hops unresolved; gaps named on the page.
  • REGISTERED = formal entry exists; run UNBOUND until a per-declaration run digest binds it. MODEL_CHECKED is reserved for that binding.
  • UNPINNED / UNREVIEWED / NOT_AUTHORIZED mean what they say.
