# How to cite

Canonical: https://svread.pages.dev/cite/

Cite the work id, the chunk locator, and the trace version hash. Statuses travel with the citation — repeat them.

Svatantrya Reader, “{work} {target} ({verses})”, `https://svread.pages.dev/claim/{work}/{target}/`, version `trace {sha}`.

COMPLETE = every applicable link resolved (not approval, proof, or witness). PARTIAL = gaps named on the page. REGISTERED = formal entry exists, run UNBOUND. UNPINNED / UNREVIEWED / NOT_AUTHORIZED mean what they say.
