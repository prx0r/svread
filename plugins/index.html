Svatantrya plugins

Start with the three bundles: Svatantrya is everything public in one install; Studio and Factory are the owner rooms. Below them, the same tools split per function for agents and power users (Nibbana Relay is private and never listed). Machine-readable spec: plugins.json.

Svatantrya https://mcp.svatantrya.net/mcp

Everything public in one install. All 40 public reads: bibliography, passages, wheels, translation briefs, formal layer, treeka chains, and the 60-level compose curriculum (levels, examples, study order).

Auth: none · Access: public — start here · Tools: 40

Install: chatgpt.com/plugins → + → Add custom MCP server → paste the URL → No authentication → Create as a plugin → Install.

  3. Show the formal coverage gaps

For agents (CLI)

  1. npx @modelcontextprotocol/inspector@latest # Transport: Streamable HTTP; URL https://<host>.svatantrya.net/mcp
  2. claude mcp add --transport http <name> https://<host>.svatantrya.net/mcp # authed: add --header "Authorization: Bearer $MCP_TOKEN"
  3. {"mcp": {"<name>": {"type": "remote", "url": "https://<host>.svatantrya.net/mcp", "headers": {"Authorization": "Bearer $MCP_TOKEN"}}}} # drop headers for the five public hosts
  4. curl -s -X POST https://<host>.svatantrya.net/mcp -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}' # SSE framing: read data: lines
  5. from fastmcp import Client async with Client('https://<host>.svatantrya.net/mcp') as c: tools = await c.list_tools() # bearer hosts: Client(url, auth=BearerAuth(token))
