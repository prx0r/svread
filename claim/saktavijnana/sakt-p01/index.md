## Passage (excerpt as hashed)

```
sthānaṃ praveśo rūpaṃ ca lakṣaṃ lakṣaṇameva ca /
utthāpanaṃ bodhanaṃ ca cakraviśrāmameva cabhūmikāgamanaṃ caiva antāvasthā tathaiva ca /
viśrāmaḥ pariṇāmaśca tathāgamanameva caiti trayodaśavidhaṃ śāktaṃ vijñānamuttamam /
sarveṣu trikaśāstreṣu sūcitaṃ śambhunā svayamnābhyadho 'ṅgulāḥ pañca meḍhrasyordhvāṅguladvayam /
tanmadhye kandanāmā ca cakrasthānamiti smṛtamprāṇāpānanirodhena manastatraiva niḥkṣipet /
samyag vāyugatiṃ jitvā yāvan madhyagatāṃ nayeteṣa praveśa ity āhū rūpaṃ vakṣyāmi cādhunā /
śṛṅgāṭakanibhaṃ cakraṃ ṣaḍaraṃ cāparaṃ dhruvamdāḍimīkusumaprakhyaṃ kandaṃ vai jātilohitam /
etadrūpaṃ samākhyātaṃ tṛtīyaṃ cintanātmakamtanmadhye nikṣipec cittaṃ yāvat tatra sthirīkṛtam /
tyaktaruddho yadā vāyustadā lakṣaṃ vinirdiśetkandacakrasya madhyasthā tv anāhatamayī kalā /
adhaūrdhve rekhāsaṃyuktā bhujaṃgakuṭilākṛtiḥūrdhvādho 'vasthitāvasthā sūryācandramasāv ubhau /
satyaṃ virājamānā sā sahasrārkasamaprabhā
```
