# Recommended study order: all 60 levels

**This is the recommended daily-focus sequence, not a mandatory lock.** Learners can open any family, make any level today’s focus, and jump to a related wheel if stuck. Within each family, `n.1` precedes `n.2`, but daily practice **interleaves families** so a learner acquires prerequisites before encountering their advanced versions. In these tables the **family number is just an ID**.

## When it gets too hard

The app suggests a set of adjacent lessons using `SWCurriculum.neighbors(levelId)`. These are **supporting exercises**, not alternative compulsory paths. Examples: if `12.1 yadā/tadā` is too hard, revisit `7.2 Time Words`; if `13.1 causatives` is too hard, revisit `8.2 Give to whom?` and `6.1 Person and Negation`; if `15.1 compounds` is too hard, revisit case relationships `8.2`. Leave the chosen daily focus unchanged while exploring, so the learner can return to it.

## Mastery and daily progression

Read `PROGRESS_AND_MASTERY.md`. Briefly: practise **one** focus for 10–15 minutes, self-grade varied combinations, level up once ready, revisit on a later day for stable mastery, and freely jump sideways for help. These are **self-report heuristics**, not verified proficiency scores. No online or cross-device persistence is claimed.
